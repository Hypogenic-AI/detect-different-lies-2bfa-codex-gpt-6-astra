\section{Reproducibility and Execution Deviations}
\label{sec:reproduction}
The workspace contains raw model outputs, activation shards, fitted probes, source/configuration hashes, and execution logs. Principal analysis artifacts are \artifact{results/summary.json}, \artifact{results/audited_summary.json}, \artifact{results/detector_metrics.csv}, \artifact{results/audited_detector_metrics.csv}, \artifact{results/subgroup_flags.csv}, \artifact{results/scored_outputs.csv}, and \artifact{results/mask_summary.json}. The experiment README supplies reproduction commands using relative project paths and the isolated dependency lockfile. Paper tables and vector plots are generated from frozen artifacts by \artifact{paper_draft/scripts/build_assets.py}; no new model experiment is needed to build the manuscript.

Two repeated analyses of cached outputs exactly matched all seven checked result files. Ten greedy model replays matched ten of ten outputs, and the prompt-continuation causality check passed with maximum difference 0.0. All 20 artifact/scientific-contract checks passed. These checks support engineering reproducibility, not latent-intent validity, sampling robustness, or adequate power.

The initial research proposal suggested 2,000 questions, more extensive matched controls, full semantic entropy, and a trained follow-up detector. Before execution, we bounded the study at 600 questions and fixed the historical model, sample, and prompts. The 100-question pilot produced no recovered incentive candidates; we retained its questions and did not tune prompts to improve yield. The predeclared feasibility concern below 50 qualifying cases is reported explicitly. The separate supervised mechanism diagnostic additionally fails its implemented minimum of ten training examples per class. We neither fit it on one positive nor substitute instructed outputs as its mechanism labels.

The separate API pilot exposed alias-scoring problems before successful local generation. We therefore added the blinded reference-equivalence audit while retaining strict scoring as primary. Universal follow-ups fill evidence missing from the pilot's initially triggered collection, preventing audit corrections from selecting which follow-ups exist. The final execution uses fixed arm order and within-arm shuffling for batch efficiency, rather than the proposed randomized arm order. Reputation is the held-out incentive family; we do not add the originally suggested third family or a supplied-fact intervention. Full entailment-based \sep and a trained follow-up probe remain unimplemented.

An initial PyTorch 2.14.1 attempt failed before generating outputs because its native Triton path required a missing C compiler. Pinning PyTorch 2.6.0 resolved inference. This failure produced no model records. Generation logs preserve ignored sampling-option warnings on greedy checks; stochastic runs explicitly set temperature, top-$p$, and top-$k$. No pending jobs are needed to interpret the reported results.
